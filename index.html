AI Use Statement
This interactive campus map was designed and coded with assistance from Antigravity AI. It uses vanilla HTML5, CSS3, and JavaScript with no external frameworks. Interactivity relies on HTML <map>/<area> tags, a canvas overlay for soft glow highlights, and CSS transforms for smooth zoom-to-location animations.
Hover to preview · Click map or list to zoom · Drag to pan when zoomed

How to use this map

Hover over any building on the map to preview details and see a soft highlight.

Click a building on the map or in the sidebar to zoom in and lock focus.

Use the search bar and category filters to browse the directory.
